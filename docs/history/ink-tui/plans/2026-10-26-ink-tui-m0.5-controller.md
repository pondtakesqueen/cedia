# Ink TUI M0.5 — Shared Controller Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract framework-agnostic controller logic from `src/clients/tui/main.ts` into `src/clients/tui/controller.ts`, shared by both pi-tui and ink TUIs. No behavior change in pi-tui (all existing tests pass). Ink app switches to use the controller.

**Architecture:** The controller owns thread store, model/permission/goal state, command dispatch, submit (runHeadless + stream decode), abort, and state events. Views (pi-tui, ink) subscribe via callbacks (`onMessage`, `onState`, `onActivity`) and render. Controller never imports pi-tui or ink.

**Tech Stack:** Bun, TypeScript, React/ink (view only), pi-tui (view only).

**Spec:** `docs/history/ink-tui/specs/2026-10-26-ink-tui-design.md` §4.1.
